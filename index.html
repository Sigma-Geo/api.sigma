Introdução

Na era da informação digital, a integração de sistemas é essencial para otimizar processos e garantir eficiência operacional. Nesse contexto, a utilização de APIs (Application Programming Interfaces) tornou-se uma prática fundamental para facilitar a troca de dados entre diferentes plataformas e sistemas, permitindo comunicação eficiente e em tempo real.

Nosso compromisso é fornecer uma solução de integração de alta qualidade, alinhada às necessidades específicas de nossos clientes, garantindo uma experiência fluida e segura em todas as etapas do processo. Por meio da API, os dados do cliente podem ser atualizados automaticamente, mantendo as informações precisas e sincronizadas em todas as plataformas.

A segurança é prioridade em todas as etapas da integração. Nossa API utiliza os mais altos padrões de proteção, incluindo protocolos avançados de criptografia e autenticação de usuário, assegurando que os dados sensíveis do cliente permaneçam protegidos contra acessos não autorizados.

Fluxo do Processo de Integração

  • Disponibilização dos dados: O cliente fornece os dados em formato JSON através de uma API no ambiente webservice.
  • Conexão com o Banco de Dados: A API se conecta a um banco de dados seguro, onde as informações do cliente são armazenadas de forma confiável.
  • Alimentação das Aplicações Web: O banco de dados abastece as aplicações web da SIGMA, garantindo que os dados do cliente estejam disponíveis para uso em nossos sistemas.

Ao longo deste documento, apresentaremos uma visão detalhada dos pré-requisitos técnicos necessários para iniciar a integração, abordando diferentes bases de dados, além de fornecer orientações sobre como manter a segurança e confiabilidade dos dados em todas as etapas do processo.

Padronização dos dados

  • Padrão: Mantenha uma padronização em todos os dados;
  • Tipo: Respeitar os tipos dos dados, mesmo que contenha apenas números, se o campo for text, mandar nesse formato;
  • Coluna: Todas as colunas da API devem ser idênticas aos da tabela;
  • Valores: Todos os valores devem estar em Maiúsculo

Autenticação e Endpoints da API

A fim de garantir a integridade e segurança da informação, será gerado um token de acesso (chave de API) único, individual e intransferível. Em caso de suspeita de vazamento, o token será revogado imediatamente e um novo será emitido.

Importante: Nunca compartilhe seu token. Ele é pessoal e intransferível.

Como usar o token (Header)

Inclua o token em todas as requisições no cabeçalho HTTP:

HeaderValor
AuthorizationBearer edc40e3b-4002-4590-9bba-847200a80e84

Exemplo completo com cURL:

curl -X GET "https://integracaotomo.sigmageotecnologias.com.br/api/historico-safra?usina=usina-exemplo" \
  -H "Authorization: Bearer edc40e3b-4002-4590-9bba-847200a80e84"

Endpoints Disponíveis

Todos os endpoints utilizam o mesmo padrão de autenticação e retornam JSON.

Introdução

Na era da informação digital, a integração de sistemas é essencial para otimizar processos e garantir eficiência operacional. Nesse contexto, a utilização de APIs (Application Programming Interfaces) tornou-se uma prática fundamental para facilitar a troca de dados entre diferentes plataformas e sistemas, permitindo comunicação eficiente e em tempo real.

Nosso compromisso é fornecer uma solução de integração de alta qualidade, alinhada às necessidades específicas de nossos clientes, garantindo uma experiência fluida e segura em todas as etapas do processo. Por meio da API, os dados do cliente podem ser atualizados automaticamente, mantendo as informações precisas e sincronizadas em todas as plataformas.

A segurança é prioridade em todas as etapas da integração. Nossa API utiliza os mais altos padrões de proteção, incluindo protocolos avançados de criptografia e autenticação de usuário, assegurando que os dados sensíveis do cliente permaneçam protegidos contra acessos não autorizados.

Fluxo do Processo de Integração

  • Disponibilização dos dados: O cliente fornece os dados em formato JSON através de uma API no ambiente webservice.
  • Conexão com o Banco de Dados: A API se conecta a um banco de dados seguro, onde as informações do cliente são armazenadas de forma confiável.
  • Alimentação das Aplicações Web: O banco de dados abastece as aplicações web da SIGMA, garantindo que os dados do cliente estejam disponíveis para uso em nossos sistemas.

Ao longo deste documento, apresentaremos uma visão detalhada dos pré-requisitos técnicos necessários para iniciar a integração, abordando diferentes bases de dados, além de fornecer orientações sobre como manter a segurança e confiabilidade dos dados em todas as etapas do processo.

Padronização do dados

  • Coluna: Todas as colunas da API devem ser identicas aos da tabela;
  • Valores: Todos os valores devem estar em Maiúsculo

Detalhamento dos Campos

chave

Chave única do talhão composta por: safra + client_id + fazenda + setor + secao + bloco + pivo + talhao , se por acaso não tiver algum desse campo, substituir por 0.

safra

Ano da safra agrícola do talhão de referência (ex: 2025 = safra 2025).

client_id

Código da SIGMA para referenciar cada cliente e suas unidades.

unidade

Nome da Usina SIGMA para referenciar ao nome fantasia da Usina/Unidade.

fazenda

Código para referenciar a fazenda.

setor

Código para referenciar o setor, se não houver, use: 0.

secao

Código para referenciar a seção, se não houver, use: "0".

bloco

Código para referenciar o bloco, se não houver, use: 0.

pivo

Código para referenciar o pivo, se não houver, use: "0".

talhao

Número para referenciar o talhão.

objetivo

Finalidade do talhão: MOAGEM ou MUDA.

tp_prop

Identificação se é uma área: PROPRIAS ou FORNECEDORES.

desc_faz

Nome completo da fazenda.

desc_cana

Estágio atual: PLANTA, MEIOSI, SOQUEIRA ou BISADA.

dt_plantio

Data real do plantio (formato DD/MM/AAAA).

tah

Valor de tonelada de açúcar por hectare.

tph

Toneladas de POL por hectare.

nmro_corte

Contagem de cortes: 1 = cana-planta, 2 = 1º soca, etc.

estagio

Estágio detalhado (ex: 18M = 18 meses, 1ºC = 1º corte, 2ºCB = 2º Corte bisada).

tch_potencial

Produtividade potencial estimada para o ambiente/variedade.

espacamento_plantado

Espaçamento planejado no plantio (metros).

espacamento_real

Espaçamento real medido no campo.

ambiente

Classificação de ambiente produtivo: A, B, C, D, E, F, G.

variedade

Código da variedade plantada, não use caracteres para separar.

maturacao

Classificação de maturação: PRECOCE, MEDIA, TARDIA.

area_bd

Área total bruta cadastrada no sistema (ha).

a_est_moagem

Área planejada para moagem na safra atual.

a_est_muda

Área planejada para produção de mudas.

a_muda

Área efetivamente utilizada para muda.

area_perda

Área perdida por erosão, inundação, etc.

a_colhida

Área já colhida na safra atual.

tch_est

Toneladas de cana por hectare estimadas.

tc_rest

Toneladas restantes no campo (estimativa).

tch_rest

TCH restante (toneladas/ha).

tc_est

Total de toneladas estimadas para o talhão.

tch_real

TCH efetivamente colhido.

tc_real

Total de toneladas efetivamente colhidas.

dt_ult_corte

Data do último corte realizado.

dt_corte

Data prevista para o próximo corte.

idade_corte

Idade do canavial no momento do corte (meses).

atr

Açúcares Totais Recuperáveis atual (kg/ton).

atr_est

ATR estimado para o corte.

irrigacao

Indica se o talhão é irrigado: NAO ou SIM.

tp_irrigacao

metodo_irrigacao

Detalhamento dos Campos

estacao

Nome identificador da estação meteorológica dentro da unidade/fazenda.

fazenda

Nome completo da fazenda onde a estação está instalada.

y_lat

Latitude da estação em graus decimais (datum WGS84). Valores negativos indicam hemisfério sul.

x_long

Longitude da estação em graus decimais (datum WGS84). Valores negativos indicam hemisfério oeste.

data / ano / mes / semana / dia

Data da medição no formato ISO 8601 (YYYY-MM-DD) e seus componentes extraídos para facilitar filtros e agrupamentos.

precipitacao

Pluviometria total acumulada no dia (mm), com separador decimal ponto.

temp_media / temp_min / temp_max

Temperaturas registradas em graus Celsius (°C), com uma casa decimal.
